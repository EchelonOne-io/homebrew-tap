# EchelonOne Homebrew tap

```sh
brew install --cask echelonone-io/tap/jimothy
```

Upgrade with `brew upgrade --cask jimothy`.

Jimothy isn't notarized yet, so the first launch asks for confirmation: open it once, then go to
**System Settings → Privacy & Security** and click **Open Anyway**.

`Casks/jimothy.rb` is updated automatically by the release workflow in
[jimothy-app](https://github.com/EchelonOne-io/jimothy-app) on each full release.
